# Homelab roadmap

## 1. Website on Cloudflare Pages
- [ ] Build the site: static files in this repo, no server needed
- [ ] Connect the repo to Cloudflare Pages and add tilenserver.com

## 2. Server
- [ ] Buy a Lenovo ThinkCentre M720s SFF with an i5 (i5-8400 or i5-9500) and a 256 GB NVMe SSD
- [ ] RAM: 16 GB as 2×8 GB
- [ ] A 3.5" HDD for photos and music (about 1 TB of photos now, room for 2 TB)

## 3. Linux, SSH and Tailscale
- [ ] Install Linux
- [ ] SSH with keys only, from the PC and the laptop; no open ports on the router
- [ ] Tailscale on the server, PC, laptop and phone

## 4. Server status on the website
- [ ] A small status endpoint on the server, coarse data only (no hostnames, IPs or versions)
- [ ] A Cloudflare Tunnel to it, so nothing at home is exposed
- [ ] The website shows the status and copes when the server is offline

## 5. Music
- [ ] Self-hosted music streaming
- [ ] Use it alongside Spotify for a month, then cancel Spotify

## 6. Photos
- [ ] Self-hosted photos
- [ ] Encrypted, versioned backups: an offsite external HDD and a cloud copy
- [ ] Restore from a backup, then delete the photos from Google
